P-WOS

Predictive Water Optimization System

An ML-driven smart irrigation framework that uses real-time sensor telemetry and crop-aware random forest models to forecast water needs, reducing consumption by ≥15% compared to traditional reactive threshold systems.

System Architecture

Edge Layer

  • ESP32-WROOM-32 microcontrollers
  • Capacitive soil moisture sensors
  • DHT22 temperature/humidity
  • MQTT telemetry publishing

Inference Layer

  • Flask REST API (Python)
  • Random Forest classifier
  • 12-feature engineering pipeline
  • VPD & evapotranspiration math

Dashboard Layer

  • React + Vite frontend
  • Real-time sensor telemetry
  • Crop configuration panel
  • ML insight visualizations

Key Achievements

  • 16.7% water savings validated against baseline threshold irrigation (target: 15%)
  • 93% ML prediction accuracy with F1 score of 0.82 using random forest classifier
  • 5 crop profiles supported with distinct irrigation thresholds and VPD responses
  • 116/116 unit validation tests passed across all system components
  • Full-stack implementation: embedded C++ firmware → Python ML API → React dashboard
